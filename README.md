# Titanic survival prediction

A Python notebook exploring the Titanic passenger dataset and a classification approach to predicting survival.

## What is here

- [titanic-ml-project.ipynb](titanic-ml-project.ipynb): the analysis and model notebook.
- [README.md](README.md): this overview.

The notebook walks through passenger features, missing values, encoding, model training, and evaluation. See its saved outputs for the specific metrics and results. The underlying data is available through [Kaggle's Titanic competition](https://www.kaggle.com/c/titanic) and is not committed here.

This is a learning project. To reproduce the work, open the notebook in Jupyter or Colab and provide the dataset at the paths expected by the code.
